# 🚀 SQL Server Data Warehouse Project (Medallion Architecture)

An end-to-end SQL Data Warehousing solution implementing the **Medallion Architecture** (Bronze, Silver, and Gold layers) using Microsoft SQL Server. This pipeline extracts raw data from multiple source files (CRM & ERP), cleanses and standardizes it, and transforms it into business-ready analytical data models.
